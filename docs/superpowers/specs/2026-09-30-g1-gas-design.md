## 1. 목표

### 1-1. 학습 핵심

**"기체의 부피는 압력과 온도에 따라 달라지고, 그 까닭은 기체 입자의 운동으로 설명된다. 온도가 일정하면 압력과 부피는 반비례하고(보일 법칙), 압력이 일정하면 온도가 높아질수록 부피가 일정한 비율로 늘어난다(샤를 법칙)."**

- **핵심 조작 동사**: 누르고 당기기(피스톤), 담그기(주사기·환자를 뜨거운 물·얼음물에), 돌리기(온도 다이얼), 끌어 대기(엑스레이 렌즈). 화면의 글을 전부 빼도 "사연 장면의 계기를 보고 같은 조절기를 돌려 환자와 같은 모양을 만든다"는 게임이 성립한다.
- **한 번에 하나만 바꾼다.** 한쪽 조절기를 쓰면 다른 쪽에 자물쇠 배지가 붙는다(6-2). 교과서의 고정 조건 문구("온도가 일정할 때", "압력이 일정할 때")가 그대로 배지가 된다.
- **조작 결과 = 진단.** 사연 장면에서 움직인 계기와 같은 조절기로 환자 모양을 재현하면 그 법칙 도장(보일 또는 샤를)이 찍힌다. 암석 순환의 "경로 선택 = 결과"를 "조절기 선택과 조작 = 법칙과 부피 변화"로 잇는다.
- **입자는 조작하는 동안 렌즈로 본다.** 압력을 바꾸면 입자 사이 거리와 충돌 횟수, 온도를 바꾸면 운동 빠르기와 충돌 세기만 강조된다(교과서가 구분한 설명).
- 문진 클릭과 진단서 퀴즈가 없어도 학습이 끝나도록, 같은 사연을 **정반대 방향으로도 한 번 재현**하게 해서(예: 눌러 보고 당겨 보기) 관계를 확인한다.

### 1-2. 성공 기준

- **한 판 10분 내외, 최대 15분**(지침 4번). 6장 표의 합계는 약 530초(9분 미만)이고, 학생의 시행착오 시간을 더해 10분 내외로 **추정**한다. 교실 실측 필요.
- 튜토리얼 + 진료 4건 + 종합 진료(응급실) 1건을 클리어하면 끝. 별과 도감은 여러 판에 걸쳐 누적된다.
- 1280×800 크롬북 터치로 끝까지 진행 가능, 키보드 대체 수단 있음(8장).
- **지름길 없음.** 측정 진료에서 피스톤을 12 mL로 바로 끌어도 1 mL 눈금마다 멈춰서 읽어야 점이 찍힌다. 잘못된 조절기로 같은 부피를 만들어도 재현으로 인정하지 않는다(5-3, 12장 테스트).
- 교과서에 없는 수치·식·용어를 쓰지 않는다(2장).

### 1-3. 범위 밖

에어 로켓 **제작**(218~219쪽, 발사 연출만 사용), 과학 신문 만들기(206쪽), 직업 가이드북·자동차 공학 기술자(216쪽), 디지털로 소통해요, 붙임딱지 생각 그물 제작(220쪽), 답 미제시 서술 활동의 정답 채점(민어 부레·밀폐 용기·스포이트 잉크·달걀·오줌싸개 인형·북극곰·주사기 속 풍선 예상), 압력 식·단위·절대 온도·기체 분자 운동, 입자 개수를 바꾸는 조작(교과서 조건이 "일정량"), 문진 단계.

## 2. 과학적 정확성 (반드시 유지)

교과서 용어·정의를 그대로 쓴다. 상세와 쪽수는 발췌 문서 2장.

| 개념 | 게임에서 지킬 것 |
|---|---|
| 압력 | 일정한 면적에 작용하는 힘의 크기. 힘이 클수록·면적이 좁을수록 커짐. 식·단위는 쓰지 않음 (198쪽) |
| 기체의 압력 | 기체 입자가 모든 방향으로 끊임없이 운동하며 벽에 충돌해 가하는 힘. 한 방향이 아님 (199, 220쪽) |
| 보일 법칙 | **온도 일정.** 누르면 압력↑ 부피↓, 당기면 압력↓ 부피↑. 반비례 = "한쪽이 커질 때 다른 쪽이 같은 비율로 작아짐". 식 없음 (202쪽) |
| 압력 변화의 입자 모형 | 입자 사이 거리·충돌 **횟수**로 설명. 입자 개수 일정, 화살표 길이는 모두 같게 (202~203쪽) |
| 샤를 법칙 | **압력 일정.** 온도↑ 부피가 "일정한 비율로" 증가, 온도↓ 부피↓. 정비례·켈빈 없음 (212쪽) |
| 온도 변화의 입자 모형 | 운동 **빠르기**·충돌 **세기**로 설명. 입자 사이 거리는 덧붙이지 않음 (213쪽) |
| 입자 표현 | "기체 입자"만 쓴다. 분자·원자 없음. 입자는 공 하나, 화살표 길이 = 운동 빠르기 (202, 222쪽) |
| 안전 | 뜨거운 물은 내열 장갑·보안경 착용 후 (210쪽). 에어 로켓은 사람을 향해 쏘지 않음 (218쪽) |
| 용어 | 압력 식·파스칼·PV=일정·절대 온도·켈빈·이상 기체·정비례·밀도·부력·운동 에너지 사용 금지 (발췌 2-9 "쓰지 않는 말") |

**이 스펙이 새로 정하는 구현 규칙 (교과서 문장에서 온 것만)**

- **수치는 화면에 쓰지 않는다**(가안 결정 4 확정). 계기 바늘과 점의 높낮이, 곡선 모양만 쓴다. 교과서에서 확인된 값(쇠구슬 20개, 20 mL에서 12 mL까지 1 mL씩, 50 mL 유리 주사기, 500 mL 비커)만 눈금·개수로 쓴다. 211쪽 온도–부피 표와 그래프 점은 원본 대조 전이라 사용하지 않는다(발췌 확인 필요 #1~#5).
- **반비례의 구현**: 압력 센서 바늘 높이는 부피의 역수에 비례하는 **상대 값**이다(부피가 반이면 바늘 높이가 2배). 교과서의 "같은 비율로 작아지는 관계" 정의를 그대로 옮긴 것이고, 기압 같은 절대 값은 표시하지 않는다.
- **일정한 비율 증가의 구현**: 온도를 같은 폭만큼 올릴 때마다 부피가 같은 폭만큼 늘어난다. 절대 온도나 식은 쓰지 않는다.
- **입자 렌즈의 강조 규칙**: 압력 조작은 (입자 개수 일정, 사이 거리, 충돌 횟수)만, 온도 조작은 (입자 개수 일정, 운동 빠르기, 충돌 세기)만 표시한다. 교과서에 없는 칸(압력 변화 때의 충돌 세기, 온도 변화 때의 사이 거리)은 강조하지 않는다. 화면에 그려지는 입자 수는 표시용 값(admin)이며 과학 내용이 아니다.
- **고정 조건 배지 문구**는 교과서 표현 그대로: "온도가 일정할 때"(줄여서 "온도 일정"), "압력이 일정할 때"("압력 일정").
- **사연 장면의 계기 그림**: 압력 사연에는 압력 센서 계기(200쪽 "압력 센서"), 온도 사연에는 온도계를 쓴다. 높은 산은 "대기압이 작아진다"(204쪽)를 압력 센서 바늘이 내려가는 그림으로 보인다. 글은 없다.
- 교과서가 답을 주지 않은 서술 활동(발췌 2-6 "답 미제시")은 환자로 쓰지 않는다. 도감에 잠긴 "숙제 카드"로만 둔다.
- 잠수부 공기 방울은 교과서가 법칙 이름을 명시하지 않아 이번 환자에서 제외한다.

## 3. 레퍼런스 게임 조사와 반영

지침 9번. 브레인스토밍 단계에서 조사했다. **확인 수준은 검색 요약이다**: PhET 공식 사이트는 이 세션의 네트워크에서 열리지 않아(접속 차단) 교육 자료 사이트·상점 페이지의 설명만 읽었고, 직접 플레이한 것은 없다.

| 레퍼런스 | 핵심 재미 (조사에서 확인된 내용) | 이 게임에서 반영한 것 | 채택하지 않은 것 |
|---|---|---|---|
| PhET 기체 성질 (Gas Properties) | 입자를 상자에 펌프로 넣고, 부피를 바꾸고 열을 더하거나 빼며 압력·온도를 재고, 입자가 튕기는 모습과 그래프를 함께 본다 | 조절기를 돌리는 동안 입자와 계기가 **실시간으로 함께 변함**(6-2, 6-7), 계기 바늘·점 곡선으로 관계 보이기(6-3) | 입자 개수를 펌프로 바꾸기(교과서 조건이 "일정량"이라 범위 밖), 중력·수치 측정 도구 |
| 병원·진료 시뮬레이터류 (Hospital Simulator: Doctor Game, Hospital Hustle) | 환자가 줄을 서고, 증상을 보고, 검사(엑스레이 등)를 골라, 진단하고 치료한다. 의사 경력이 단계로 오른다 | 대기실 환자 줄, 검사 장치, 엑스레이 렌즈, 진단 도장, "견습에서 전문으로" 직함(7장) | 치료·병원 경영·직원 고용, 문진(질문 고르기) |
| Peggle | 튕김과 연쇄에 **리듬 있는 효과음·빛**을 붙여 "한 번만 더"를 만든다 | 입자가 벽에 부딪힐 때 톡 소리와 섬광(렌즈 안), 연속 진료 성공을 **콤보**로 쌓아 튀어 오르는 숫자(6-6, 8장) | 조준 발사, 제한된 공 수 |
| Cooking Mama | 요리 한 단계가 10초 안팎의 미니게임이고, 잡기·끌기·문지르기 같은 **터치 동작이 실제 행동과 닮았다** | 구슬 흔들기 튜토리얼, 응급실의 빠른 연속 라운드(6-6), 설명 없이 손이 가는 조작 | 단계마다 등급을 주는 평가 화면 |

**반영 요약**
1. **조작이 곧 관찰**(PhET): 별도 관찰 화면을 두지 않고 조작하는 장치 위에 렌즈를 댄다.
2. **진단 흐름의 문법**(진료 시뮬레이터): 증상 보기 → 검사 → 진단 도장 순서는 학생에게 이미 익숙하다. 다만 "질문 고르기" 단계는 클릭 선택이라 지침 2번에 맞지 않아 뺐다.
3. **충돌의 쾌감**(Peggle): 입자 충돌 피드백을 소리·빛으로 키운다. 성공 피드백 강화(지침 7번)의 재료가 된다.
4. **짧은 제스처 미니게임**(Cooking Mama): 종합 진료를 15~20초 라운드 4개로 구성한다.

출처는 문서 끝 "출처"에 모았다.

## 4. 화면 흐름

```
[타이틀]  시작 = 전체 화면 요청 (첫 터치가 곧 전체 화면)
   |
[인트로]  진료소장 대사 2문장
   |
[튜토리얼] 구슬 흔들기 (손을 흔들면 구슬이 벽을 친다)
   |
[대기실]  환자 줄 + 진료 차트 (클리어 표시)       <---------------+
   |  환자를 끌어 검사 장치에 올림 (또는 탭)                        |
   v                                                               |
[사연 장면]  글 없는 2~3초 애니메이션 + 계기 바늘·눈금이 움직임     |
   |                                                               |
[검사 장치]  피스톤 손잡이 + 온도 다이얼/물통, 환자 모양의 그림자  |
   |  같은 계기의 조절기를 돌려 환자와 같은 모양 재현              |
   |  (압력 센서 계기, 온도계, 고정 배지, 엑스레이 렌즈)            |
   v                                                               |
[진단서]  법칙 도장 + 교과서 한 줄(2문장 이내) + 도감 등록 ----------+
   |  (진료 4건 반복)
   v
[응급실]  사연이 바뀌는 환자 4명, 15~20초 라운드 (종합 진료)
   |
[엔딩]  오늘의 진료 차트 + 에어 로켓 발사 피날레(3~5초)
   |
[요약 팝업]  결과 요약 + "나의 결과 내려받기"(PNG) + 도감 진행률
```

- **phase**: `title → intro → tutorial → clinic → story → exam → diagnosis → clinic … → emergency → ending → result`. 전이는 `game/store.ts`의 `start/next/enterExam/finishStory/completeExam/finishEmergency/restartRun/reset`만 쓴다(임의 점프 금지).
- **환자 순서**(5-1 표): 튜토리얼 → 고무공(압력, 측정) → 과자 봉지(압력, 재현) → 은박 풍선(온도, 담그기) → 축구공(온도, 재현) → 응급실 4명.
- 문진 화면이 없다. 틀린 조절기를 돌려도 막지 않고 **한 줄로 이유만** 알려 준다(6-2): 예) "사연에서 바늘이 움직인 계기를 찾아요."
- 대사(인트로·엔딩·진단서)는 한 번에 1~2문장. 읽는 장면(인트로·진단서·요약)은 글 중심, 조작 장면(검사 장치)은 **손 모양·반짝임·화살표로 안내**하고 글을 넣지 않는다.
- 새로고침하면 진행 중인 진료는 그 환자의 사연 장면부터 다시 시작한다. 클리어한 진료와 별·도감은 유지된다.

### 5-3. 판정 규칙 (`game/rules.ts`, 순수 함수)

과학 계산은 이 파일에만 둔다. 씬과 오버레이는 호출만 한다.

- `lawOf(variable)` → `boyle | charles`
- `volumeDirection(variable, change)` → `increase | decrease` (압력↑ 부피↓, 압력↓ 부피↑, 온도↑ 부피↑, 온도↓ 부피↓)
- `needleFromVolume(volume)` → 바늘 상대 높이(부피의 역수에 비례), `volumeFromTemp(step)` → 같은 폭씩 증가
- `lockOf(usedVariable)` → `{ locked: 'temperature' | 'pressure', badge }`
- `particleView(variable, change)` → 입자 렌즈에서 강조할 항목과 방향. `null` 칸은 강조하지 않음
- `matchExam(exam, state)` → `{ ok, reason }`: 사용한 조절기가 `exam.variable`과 같고, 부피가 목표 모양의 허용 오차 안에서 유지 시간 이상 머물면 성공. 다른 조절기로 같은 부피를 만들어도 `reason: 'wrong-gauge'`
- `checkPistonRun(readings)`: 20 mL에서 12 mL까지 눈금을 **모두** 눈금 멈춤 시간 이상 머물며 읽었는지
- `checkSafetyGear(gear)`, `checkSubmerged(syringe, bath)`(기체가 모두 잠겼는지), `checkLensObserved(state)`(렌즈를 댄 채 조절기를 일정 시간 움직였는지)
- `scoreStars(result)`, `comboOf(history)`

### 5-4. 퀴즈와 확인 (지침 3번: 퀴즈 비중을 낮춘다)

- **플레이 흐름에 퀴즈 단계를 두지 않는다.** 확인은 조작으로 한다: 반대 방향 재현(눌러 본 뒤 당겨 보기), 응급실 4명의 재현.
- 학습 정리는 클리어 **뒤** 진단서(교과서 한 줄, 2문장 이내)와 요약 팝업, 도감에 모은다. 예) "온도가 일정할 때 기체의 압력과 부피는 반비례해요. 압력이 커지면 입자 사이 거리가 가까워져 충돌 횟수가 많아져요."
- 발췌 3장의 퀴즈 원천(약 44행)은 **도감 카드의 "확인해 보기" 선택 활동**과 이후 추가 후보로 남긴다. 필수 흐름에는 넣지 않는다.

### 5-5. 별점과 한 판 판정

- 진료 하나당 별 최대 3개: ① 첫 조작이 사연 계기와 같은 조절기 ② 제한 시간(admin, 기본 60초) 안에 재현 ③ 보조 과제(고무공: 눈금 9개 모두 읽기, 은박 풍선: 안전 장비를 먼저 착용, 그 밖: 렌즈로 관찰)
- 응급실은 라운드 4개 성공 수와 콤보로 별 0~3개.
- 한 판 판정: 튜토리얼 + 진료 4건 + 응급실 완료. 별이 적어도 끝까지 진행된다(실패로 막지 않음). 오답 시 별만 깎이고 재시도 가능.
- 진행 저장: `localStorage`(`air-clinic-run-v1`, 도감 `air-clinic-dex-v1`). 전이는 store 액션으로만 바뀐다.

### 6-0. 공통: 공간감과 비언어 안내 (지침 2·3번)

- **시점**: 검사대는 살짝 위에서 내려다본 3/4 시점. 주사기·비커·스탠드를 사선으로 그리고, 물통은 앞 벽이 뒤 벽 위에 겹치도록 **깊이 정렬**한다. 앞쪽 물건은 조금 크게, 뒤쪽은 작게(원근).
- **그림자**: 모든 기구 아래에 부드러운 그림자. 드래그로 집어 올린 물건은 **그림자가 멀어지고 살짝 커진다.** 놓으면 톡 내려앉는다.
- **안내는 글 없이**: 처음 조작할 조절기 위에 손 모양이 끌어가는 모양으로 반복, 놓을 자리는 반짝이는 테두리, 목표 눈금은 계기의 **고스트 표시**, 다음에 돌릴 다이얼은 맥박처럼 커졌다 작아지는 고리. 글은 단추 이름표·배지("온도 일정")·한 줄 실패 이유뿐이다.
- 모든 드래그는 잡는 영역을 넉넉히(터치 44 px 이상), 놓을 자리는 눈에 띄게 강조.

### 6-1. 구슬 흔들기 (튜토리얼, 199쪽, ~60초)

- 쇠구슬 20개가 든 페트병을 **좌우로 드래그해 흔든다.** 구슬이 벽에 부딪힐 때마다 톡 소리와 작은 섬광이 나고, 옆의 **손바닥 힘 게이지**가 오른다. 천천히 흔들면 조금, 세게 흔들면 많이 오른다.
- 게이지가 가득 차면 "기체의 압력" 카드(한 줄: 입자가 모든 방향으로 벽에 부딪혀 힘을 가해요)가 나오고 도장이 튄다.
- 키보드: ←→를 **번갈아** 누른다(키를 누르고 있어도 `e.repeat`는 무시되어 오르지 않는다).
- 입자 = 쇠구슬 비유(199쪽)가 이 장면의 전부다. 압력 정의나 면적 바꾸기는 여기서 다루지 않고 도감 카드에 그림으로 둔다.

### 6-2. 검사 장치 (모든 진료 공통)

- 장치 구성: **주사기**(피스톤 손잡이 + 눈금) + **압력 센서 계기** + **물통**(온도계, 온도 다이얼) + **렌즈 거치대**.
- 환자는 **환자 모양의 그림자(고스트)**로 장치 위에 떠 있고, 학생이 만든 주사기 속 기체의 크기가 이 그림자와 겹치면 재현이다.
- **한 번에 하나만 바꾸기**: 피스톤을 움직이면 물통 쪽에 자물쇠가 붙고 "온도 일정" 배지가 켜진다(다이얼 잠김). 다이얼이나 물통을 쓰면 피스톤이 압력을 맞추며 저절로 움직이고 "압력 일정" 배지가 켜진다(손잡이 잠김). 다른 쪽을 쓰려면 원점으로 돌린다.
- **재현 조건**: 사연에서 움직인 계기와 같은 조절기를 썼고, 부피가 목표 모양의 허용 오차 안에서 유지 시간(admin) 이상 머문다. 계기에는 목표 눈금의 고스트가 뜬다.
- **다른 조절기를 쓴 경우**: 막지 않는다. 부피가 같아져도 재현으로 치지 않고 한 줄로 이유만 알려 준다("사연에서 바늘이 움직인 계기를 찾아요"). 별 ①을 잃고 다시 시도.
- 첫 진료(고무공)는 피스톤만 열려 있고 다른 조절기는 흐릿하다. 둘째 진료(과자 봉지)부터 두 조절기가 모두 열린다.

### 6-3. 측정 진료: 고무공 (200~202쪽, ~90초)

- 사연: 사람이 공 위에 앉는다 → 압력 센서 바늘이 오른다.
- 피스톤을 **드래그로 눌러** 20 mL에서 12 mL까지 **1 mL 눈금마다 딸깍** 멈춰 읽는다(키보드 ↑↓로 1 mL씩). 눈금에 머물 때마다 압력 센서 바늘이 오르고 작은 그래프에 **점이 하나씩** 찍혀 반비례 곡선 모양이 된다(수치 없음, 모양만).
- 끝까지 읽으면 이어서 피스톤을 **당겨** 본다(반대 방향 확인). 눌렀을 때 바늘이 오르고 당겼을 때 내리는 것이 한 번에 보인다.
- 렌즈를 대면 입자 사이 거리가 눌릴수록 가까워지고 벽 충돌 섬광이 잦아진다(6-7). 성공하면 **보일 법칙 도장**.
- 지름길 없음: 눈금을 건너뛰면 그 눈금의 점이 안 찍히고 `checkPistonRun`이 미완으로 본다.

### 6-4. 담그기 진료: 은박 풍선 (210쪽, ~90초)

- 사연: 추운 밖에서 쭈글쭈글, 온도계 눈금 하강.
- 먼저 **장갑·보안경**을 끌어 착용한다(안 하면 뜨거운 물 비커가 흔들리며 거부, 글 없이 손 모양 안내). 그 뒤 **주사기를 끌어** 뜨거운 물 비커에 담근다(기체가 모두 잠겨야 함). 피스톤이 위로 올라가 부피가 늘어난다. 이어서 얼음물 비커에 담그면 줄어든다.
- 렌즈를 대면 입자의 **화살표가 길어지고 충돌 섬광이 세진다**(6-7). 성공하면 **샤를 법칙 도장**.
- 환자 그림자는 팽팽한 은박 풍선이다. 뜨거운 물로 부피가 그 모양에 닿으면 "다시 팽팽해졌다" 연출.

### 6-5. 재현 진료: 과자 봉지, 축구공 (204, 207, 214, 217쪽, 각 ~60초)

- 사연 장면(산 위 또는 겨울 바깥)을 보고, 같은 계기의 조절기(압력 센서 → 피스톤, 온도계 → 다이얼)를 돌려 환자 그림자와 같은 크기를 만든다.
- 과자 봉지: 피스톤을 **당겨** 부풀린다. 축구공: 다이얼을 **낮춰** 줄인다. 성공하면 반대 방향(눌러 보기, 올려 보기)을 한 번 더 해 보라는 **손 모양 안내**가 나오고, 한 번 해 보면 도장이 찍힌다.
- 렌즈는 선택이다. 대면 보인다.

### 6-6. 응급실: 종합 진료 (~75초)

- 환자 4명(탁구공·공기 침대·열기구·운동화)이 15~20초 간격의 **라운드**로 차례로 들어온다. 사연 장면은 1.5초, 그 뒤 해당 조절기를 한 번 끌거나 돌려 재현한다. 탁구공은 뜨거운 물에 끌어 담가 편다.
- 연속 성공은 **콤보**로 쌓인다. 숫자가 튀어 오르고 효과음 음높이가 올라간다.
- 4명 모두 마치면 진료 차트가 채워지고 엔딩으로 이어진다. 놓친 환자는 마지막에 한 번 더 온다.

### 6-7. 엑스레이 렌즈 (입자 보기)

- 렌즈 아이콘을 **끌어 검사 장치 위에 대면** 주사기 속이 확대되어 입자가 보인다. 떼면 원래 화면. 키보드: `L`로 켜고 끈다.
- 입자는 공 하나이고 화살표 길이가 운동 빠르기다(202, 222쪽). 렌즈를 댄 채 조절기를 움직이면 입자가 **실시간으로** 변한다.
  - 압력 조작: 입자 개수 그대로, 사이 거리가 변하고, 벽 충돌 섬광의 횟수가 변한다. 화살표 길이는 모두 같다.
  - 온도 조작: 입자 개수 그대로, 화살표 길이(빠르기)와 충돌 섬광의 세기가 변한다.
- 충돌마다 톡 소리와 섬광(효과음은 겹치지 않게 제한)으로 Peggle식 리듬 피드백을 준다.
- 렌즈 관찰은 `checkLensObserved`로 기록하고, 고무공·은박 풍선 진료에서 한 번씩 하면 입자 카드(압력용, 온도용)를 도감에 등록한다.

### 6-8. 피날레 (에어 로켓, 3~5초)

- 응급실 완료 → 잠깐 멈춤 → 펌프 손잡이를 **연타**(2초 이내, `e.repeat` 무시, 건너뛰기 가능) → 에어 로켓이 하늘로 발사되고 빛이 터진다 → 팡파르와 배경음 전환 → 별·점수 카운트업 → 요약 팝업.
- 에어 로켓의 원리는 교과서가 설명하지 않으므로(218~219쪽) 글로 설명하지 않는 **연출**이다. 로켓은 위쪽 하늘로만 발사한다(사람을 향해 쏘지 않음, 218쪽).

## 7. 주인공·진료 기록부

- **주인공**: 견습 공기 의사. 물질 분리 공방·입자 공작소의 **견습생 그림을 가운만 바꿔 재사용**(시리즈 일관성, 그림 비용 절감). 진료소장 NPC는 새로 만든다. 직함은 별 합계로 오른다(견습 공기 의사 → 공기 의사 → 공기 박사, 기준은 admin).
- **진료 기록부(도감)**:
  - 증상 카드: 치료한 환자마다 1장(교과서 쪽수 포함). 교과서에 있지만 이번에 환자로 쓰지 않은 사례와 답 미제시 사례 5건은 **잠긴 숙제 카드**(쪽수만, 답 없음).
  - 법칙 도장 2(보일·샤를), 입자 엑스레이 카드 2(압력용·온도용).
  - 인물 카드 2: 보일(영국, 1627~1691), 샤를(프랑스, 1746~1823). 교과서에 적힌 내용만.
- **요약 팝업**: 오늘 치료한 환자 수, 별 합계, 새로 얻은 카드, 잘못 돌린 조절기 횟수, 진료 차트 2줄(압력 ↔ 부피 온도 일정 / 온도 ↔ 부피 압력 일정), "나의 결과 내려받기".

## 8. 공통 요소와 입력 견고성 (지침 6·7번)

- **시작 버튼 = 전체 화면 요청.** 별도 안내 단계 없음. 오른쪽 위에 전체 화면·음소거 단추(누른 뒤 초점 해제).
- 키 자동 반복(`e.repeat`) 무시. 대사·카드·진단서·요약 전환 뒤 **0.7~1.5초 입력 잠금**(`useLock`, admin에서 값 조정). 연출 중에도 잠금을 지키되 잠금이 풀리면 건너뛸 수 있다.
- 드래그는 포인터 캡처를 쓰고, 캔버스 밖에서 손을 떼거나 취소되면(`pointerup`·`pointercancel`·`lostpointercapture`) 해제한다. 주사기를 놓지 못한 채 끝나는 일이 없도록 놓을 자리 밖에서 떼면 원위치로 돌아간다.
- 새로고침해도 진행이 꼬이지 않는다(persist, 전이는 store 액션뿐).
- 키보드 대체: 피스톤 ↑↓, 다이얼 ←→, 렌즈 `L`, 환자 선택 Tab/Enter, 흔들기 ←→ 번갈아.
- **성공 피드백은 강하게**(지침 7번). 작은 성공(눈금에 딸깍·제 자리에 놓기): 대상이 튀어 오르는 스케일 팝, 반짝임·파티클, 밝은 효과음. 진료 성공: 환자 모양이 펴지는 애니메이션 + 번쩍임 + 도장이 쿵 찍힘 + 별 획득. 응급실 콤보: 튀어 오르는 숫자와 올라가는 음높이. 최종 피날레 4초(6-8). 실패는 짧고 가볍게.
- 음원: 정답·오답·성공·배경음은 기존 음원을 재활용(`public/assets/audio/`). **새로 필요한 소리**(눈금 딸깍, 피스톤 쉬익, 물 담그기 첨벙, 입자 충돌 톡, 도장 쿵, 팡파르, 로켓 발사)는 `tgtec26/local-game-audio-studio`에서 기본 음원을 제작해 배치하고, 더 나은 것이 필요할 때만 대치한다.
- 이모지 없음. 용어는 교과서대로.

## 11. 오류 처리

- JSON 검증 실패: 해당 탭에 오류 위치 표시, 저장 거부. 게임은 마지막으로 유효했던 데이터로 동작하지 않고 **로딩 오류 화면**을 보인다(데이터 없이는 판정 불가).
- `verified: false` 데이터는 게임에서 쓰지 않는다(테스트로 고정).
- 전체 화면 거부(인앱 브라우저 등)는 조용히 무시한다. 그림 파일이 없으면 SVG 플레이스홀더로 대체하고 404를 내지 않는다(manifest에 적힌 파일만 요청).
- 저장 데이터 버전이 다르면 이어하기를 버리고 새 판으로 시작한다.
