## 1. 학습 핵심

**"기체의 부피는 압력과 온도에 따라 달라지고, 그 까닭은 기체 입자의 운동으로 설명된다. 온도가 일정하면 압력과 부피는 반비례하고(보일 법칙), 압력이 일정하면 온도가 높아질수록 부피가 일정한 비율로 늘어난다(샤를 법칙)."**

- **한 번에 하나만 바꾼다** → 온도를 일정하게 두고 압력만, 압력을 일정하게 두고 온도만 바꿔야 관계가 보인다.
- **압력이 커지면** 부피가 줄고, 입자 사이 거리가 가까워져 벽에 더 많이 충돌한다 (입자 개수는 그대로).
- **온도가 높아지면** 입자 운동이 빨라져 벽에 강하게 충돌하고 부피가 늘어난다.
- 생활 속 현상은 "압력이 달라졌나, 온도가 달라졌나"를 찾으면 풀린다.
- 게임에서는 **문진에서 고른 원인 = 들어갈 검사실(어느 법칙), 검사실 조작 결과 = 부피와 입자의 모습**. 암석 순환의 "선택 = 결과, 조작 결과 = 특징"을 "원인 선택 = 법칙, 조작 = 부피 변화"로 잇는다.

## 2. 과학적 정확성 (반드시 유지)

교과서 용어·정의를 그대로 쓴다. 상세는 발췌 문서 2장.

| 개념 | 게임에서 지킬 것 |
|---|---|
| 압력 | 일정한 면적에 작용하는 힘의 크기. 힘이 클수록·면적이 좁을수록 커짐. 식·단위는 쓰지 않음 (198쪽) |
| 기체의 압력 | 기체 입자가 모든 방향으로 끊임없이 운동하며 벽에 충돌해 가하는 힘. 한 방향이 아님 (199, 220쪽) |
| 보일 법칙 | **온도 일정.** 누르면 압력↑ 부피↓, 당기면 압력↓ 부피↑. 반비례 = "한쪽이 커질 때 다른 쪽이 같은 비율로 작아짐". 식 없음 (202쪽) |
| 압력 변화의 입자 모형 | 입자 사이 거리·충돌 **횟수**로 설명. 입자 개수 일정, 화살표 길이는 모두 같게 (202~203쪽) |
| 샤를 법칙 | **압력 일정.** 온도↑ 부피가 "일정한 비율로" 증가, 온도↓ 부피↓. 정비례·켈빈 없음 (212쪽) |
| 온도 변화의 입자 모형 | 운동 **빠르기**·충돌 **세기**로 설명. 입자 사이 거리는 덧붙이지 않음 (213쪽) |
| 입자 표현 | "기체 입자"만 쓴다. 분자·원자 없음. 입자는 공 하나, 화살표 길이 = 운동 빠르기 (202, 222쪽) |
| 수치 | 20 mL→12 mL(1 mL씩), 쇠구슬 20개 등 교과서 값만 확정. 압력 센서 값·211쪽 온도–부피 표·그래프 점은 **확인 필요**라 정성적으로만 (발췌 2-9 #1~#5) |
| 생활 사례 | 분류는 교과서 배치를 따름 (압력–부피 9, 온도–부피 10). 답 미제시 5건(민어 부레·밀폐 용기·스포이트 잉크·달걀·오줌싸개 인형)은 정답으로 채점하지 않음 |
| 안전 | 뜨거운 물은 내열 장갑·보안경 착용 후 (210쪽). 에어 로켓은 사람을 향해 쏘지 않음 (218쪽) |
| 용어 | 압력 식·파스칼·PV=일정·절대 온도·켈빈·이상 기체·정비례·밀도·부력·운동 에너지 사용 금지 |

- 열기구는 "가벼워져 떠오른다"까지만 설명한다 (214쪽). 밀도·부력으로 풀지 않는다.
- 검사실 화면에는 **고정 조건 배지**를 붙인다: 피스톤 검사실 "온도 일정", 온탕 검사실 "압력 일정" (교과서 조건 문구).

## 3. 게임 한 줄 요약

주인공은 마을 **"공기 진료소"의 견습 공기 의사**. 대기실에 **찌그러진 탁구공, 쭈글쭈글한 은박 풍선, 빵빵한 과자 봉지**가 환자로 줄을 선다. 견습 의사는 **문진**(누르는 힘이 달라졌나? 온도가 달라졌나?)으로 원인을 고르고, **검사실**에서 주사기를 누르고 당기거나 뜨거운 물·얼음물에 담가 부피가 어떻게 변하는지 직접 만든다. **입자 엑스레이**로 입자 사이 거리·충돌·운동 빠르기를 확인하면 **진단서에 보일 법칙 또는 샤를 법칙 도장**이 찍힌다. 마지막 **종합 진료**에서는 압력 환자와 온도 환자가 섞여 들어온다.

## 4. 구조 (진료소 지도 + 진단 흐름, `ClinicScene`)

이 단원의 과학 구조는 **"변인 하나를 바꾸고 하나는 고정한다"는 병렬 두 관계 + 입자 모형 해석 + 생활 적용**이다. 위계(입자 공작소)나 순환(암석)이 아니라 **두 갈래 검사실이 입자 엑스레이로 합쳐지는 진단 흐름**으로 짠다.

```
[대기실: 환자 카드]  증상 = 부피가 변함 (찌그러짐 / 팽팽함 / 부풂)
        │
   [문진] 무엇이 달라졌나?      ← 원인 선택 = 어느 법칙
        │
  ┌─────┴───────────────┐
[압력이 달라졌다]      [온도가 달라졌다]
 피스톤 검사실          온탕·얼음탕 검사실
 (온도 일정 배지)       (압력 일정 배지)
 누르고 당기기          주사기 담그기
  └─────┬───────────────┘
[입자 엑스레이]  압력: 거리·충돌 횟수 │ 온도: 빠르기·충돌 세기 │ 입자 개수 일정
        │
[진단서]  보일 / 샤를 도장 → 도감 등록
        │
[종합 진료]  섞인 환자 → 문진부터 (별점)
```

- **진료 하나 = 환자 하나.** 환자 카드에 증상(교과서 한 줄)만 있고, 원인은 문진과 검사실 조작 결과로 정해진다.
- **문진이 갈림길**이다. 틀리면 교과서 근거 한 줄로 막는다: 과자 봉지를 "온도"로 고르면 "높은 곳에서는 대기압이 작아져요 (204쪽)", 탁구공을 "압력"으로 고르면 "뜨거운 물에 넣으면 기체 부피가 늘어요 (217쪽)". 틀려도 재선택 가능, 첫 시도 성공만 별.
- **검사실은 증상 재현**이다. 환자 대신 주사기 모형으로 같은 부피 변화를 만들어 원인을 확인한다. 기체 부피가 증상과 같은 방향으로 움직이면 확정.
- **입자 엑스레이**는 두 검사실 공통 화면. 압력 환자는 입자 사이 거리·충돌 횟수, 온도 환자는 운동 빠르기·충돌 세기만 켜진다 (교과서가 구분한 설명).
- **튜토리얼**은 구슬 흔들기(199쪽) + 면적 바꾸기(198쪽)로 "압력"이 무엇인지 체험한 뒤 첫 진료(고무공)로 이어진다.
- **종합 진료**(220~223쪽 마무리 문제 성격): 압력 환자 2 + 온도 환자 2를 섞어 받는다. 잠수부 공기 방울·액체 질소 풍선 같은 문제 속 사례를 쓴다.

## 6. 진행·보상

- **진료 기록부(도감)** 3장:
  - 증상 카드: 교과서 생활 사례 (압력–부피 9, 온도–부피 10. 답 미제시 5건은 "숙제 카드"로 표시, 쪽수 포함).
  - 법칙 도장 2(보일·샤를)와 입자 엑스레이 카드 2(압력용·온도용).
  - 인물 카드 2: 보일(영국, 1627~1691), 샤를(프랑스, 1746~1823). 교과서에 적힌 내용만.
- **한 판 = 튜토리얼 + 진료 5건, 12분 내외 (최대 15분).**

| 구간 | 내용 | 시간 |
|---|---|---|
| 튜토리얼 | 구슬 흔들기 + 면적 바꾸기 | 1분 |
| 압력 진료 2건 | 고무공 → 피스톤 검사 + 엑스레이 / 과자 봉지 또는 공기 침대 | 4분 |
| 온도 진료 2건 | 은박 풍선 → 온탕·얼음탕 + 엑스레이 / 탁구공 → 생활 진단 | 3.5분 |
| 종합 진료 1건 | 섞인 환자 4명 문진 + 생활 진단 | 2분 |
| 퀴즈 | 진단서마다 1문항 (5문항) | 1.5분 |

- **별점**: 문진 원인 첫 시도 + 검사실 조작 정확도(눈금·잠김·입자 배치·안전 장비) + 진단서 후 퀴즈 1문항 (발췌 3장 35행에서 출제).
- **엔딩**: 오늘의 진료 차트 — "압력 ↔ 부피 (온도 일정)", "온도 ↔ 부피 (압력 일정)" 두 줄 요약, 220쪽 생각 그물 모양의 핵심 단어 붙이기 한 장, 에어 로켓 발사 연출, 도감 진행률.

## 7. 기술 (암석 순환·물질 분리 공방 구조 재사용)

- Next.js 16 + Phaser 4 + zustand (`game/store.ts` 전이 액션만). Phaser 캔버스(진료소 배경·검사실·엑스레이 연출) + React 오버레이(문진·미니게임 조작).
- `game/rules.ts` 순수 함수 (제안):
  - `lawOf(variable)` → `boyle | charles`
  - `volumeDirection(variable, change)` → `increase | decrease` (압력↑ 부피↓, 온도↑ 부피↑)
  - `particleChanges(variable, change)` → 증가·감소·일정 표. 교과서 207·217쪽에 있는 칸만 값을 주고 나머지는 `null`
  - `diagnose(caseId, chosenVariable)` → `{ ok, law, page }` (틀리면 교과서 쪽수 근거)
  - `checkPistonRun(readings)` (20→12 mL, 1 mL 간격 기록 여부), `checkSubmerged(syringe, bath)`, `checkSafetyGear(gear)`, `checkParticleDrawing(before, after)` (개수·화살표 길이·간격)
